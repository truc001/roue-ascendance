# Roue d'ascendance

Site web pour remplir facilement une roue d'ascendance généalogique (numérotation Sosa), puis l'exporter en image ou l'imprimer.

- Cliquez sur une case pour saisir la personne : prénom, nom, naissance, décès, profession, notes. La touche Entrée passe à la case suivante.
- De 2 à 8 générations, en roue complète, en éventail à 270° ou en demi-roue, avec trois jeux de couleurs.
- Import d'un fichier GEDCOM (Geneanet, Heredis, Ancestry…).
- Export PNG haute définition ou SVG, impression / PDF.
- Sauvegarde automatique dans le navigateur, et sauvegarde/ouverture d'un fichier `.json`.

Aucune donnée n'est envoyée sur un serveur : tout reste dans le navigateur de la personne qui utilise le site.

## Utilisation

Ouvrir `index.html` dans un navigateur. Il n'y a aucune dépendance ni étape de compilation.
